# Testing Steering

## Property Tests (`kiri_check`)
1. **Week Monotonicity:** For any valid last menstrual period (LMP) or due date, calculated gestational week is between 4 and 42 and never moves backward on successive days.
2. **Paused Immunity:** While paused state is active, zero baby messages or costume assets are returned.
3. **Parity Check:** For every screen and mode, switching between Everyday and Halloween renders identical interactive widget types and counts.
4. **Content Gate:** Loading unapproved or banned lines throws a validation error.

## Unit & Widget Tests
- Pure unit tests for date and week calculation.
- Widget tests checking contrast ratios and touch target bounds.
