# Requirements: Settings Screen

## R1 — Access
**WHEN** the mother taps a Settings icon (in TopBar or bottom nav overflow),
**THE SYSTEM SHALL** open the Settings screen.

## R2 — About
**WHEN** Settings opens,
**THE SYSTEM SHALL** display the app name, version string, and the full
medical disclaimer: "This app is not medical advice. If you are worried
about anything, call your doctor."

## R3 — Lamp preference shown
**WHEN** Settings is open,
**THE SYSTEM SHALL** show the current mode (Everyday / Halloween) and
allow switching it — same as the lamp toggle, for discoverability.

## R4 — Erase all data
**WHEN** the mother taps "Erase all data" in Settings,
**THE SYSTEM SHALL** show the same confirmation dialog as Pause → Erase,
then clear all prefs and return to First Run.

## R5 — App voice only
**WHEN** Settings is displayed,
**THE SYSTEM SHALL** use App Voice — no baby narration, no costume images.

## R6 — Privacy statement
**WHEN** Settings is open,
**THE SYSTEM SHALL** display: "No data ever leaves your phone.
No accounts. No tracking. No ads."
