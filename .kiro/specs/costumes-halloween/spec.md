# Spec: Costumes & Halloween Mode

## Requirements
1. **WHEN** the lamp is toggled off, **THE SYSTEM SHALL** switch the theme palette to midnight plum and equip the baby with the costume corresponding to today's need.
2. **WHEN** displaying costumes, **THE SYSTEM SHALL** support Vampire (Iron), Mummy (Water), Witch (Vitamin), Ghost (Rest), Skeleton (Bones), and Zombie (Brain).
3. **WHEN** in Everyday mode, **THE SYSTEM SHALL** display the baby in the onesie with equivalent need tag.
4. **WHEN** switching modes, **THE SYSTEM SHALL** maintain 100% interactive parity across all screens.
