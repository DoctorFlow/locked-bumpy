# Spec: App Shell and Theme

## Requirements
1. **WHEN** the app opens for the first time, **THE SYSTEM SHALL** display the First Run onboarding allowing the mother to set her due date or last menstrual period (LMP) and choose an initial look (Everyday or Halloween).
2. **WHEN** on the main navigation shell, **THE SYSTEM SHALL** provide 3 core tabs: Today (Tab 1), This Week (Tab 2), and Guides (Tab 3).
3. **WHEN** switching modes via the Lamp toggle, **THE SYSTEM SHALL** smoothly transition the theme palette between Everyday (lamp on) and Halloween (lamp off) with 100% UI element parity.
4. **WHEN** Pause is triggered from any tab or settings, **THE SYSTEM SHALL** immediately replace the view with the neutral, quiet Paused screen in app voice.
5. **WHEN** running on web, **THE SYSTEM SHALL** constrain layout to a mobile aspect ratio (phone width) and execute with zero external network calls.
